Keyboard Shortcuts

Double-click
Create a card on the canvas
Drag canvas

Shift + drag card
Draw a connection to another card
Double-click connection
Edit connection label
Hover connection + Enter
Edit connection label
Backspace / Delete
Delete selected card or connection
Two-finger scroll
Pan the canvas
Pinch / Ctrl + scroll
Zoom in and out
Middle-mouse drag
Pan the canvas
0

F

Click frame, then drag
Select then move the frame and all its cards
Double-click frame

Double-click frame label
Rename the frame
Space + drag card
Escape a frame — frame shrinks to exclude the card
Enter on selected card
Enter the card as a container (stacked cards have children)
Esc
Exit container scope
Ctrl / ⌘ + Z
Undo (structural changes; drags are not undoable)
Ctrl / ⌘ + Shift + Z
Redo
